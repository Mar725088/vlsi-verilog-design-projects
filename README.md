## 📑 Key Academic Projects

### 1. ⚡ Design and Implementation of 16-bit ALU with Radix-2 Booth Multiplier on FPGA
* **Domain:** VLSI & Digital Systems Design (M.Tech Project)
* **Key Highlights:**
  * Designed a high-performance **16-bit ALU** integrated with a **Radix-2 Booth Multiplier** for fast signed multiplication.
  * Performed functional verification and timing validation targeting **Xilinx FPGA boards**.
  * Optimized architecture for resource utilization and execution speed compared to conventional multiplier circuits.
* **Tools Used:** Verilog HDL, Xilinx Vivado, ModelSim

## 💻 How to Run Simulations

1. Clone or download this repository.
2. Open **Xilinx Vivado** or **ModelSim**.
3. Create a new project and add the design `.v` files along with testbenches (`tb.v`).
4. Run **Behavioral Simulation** to observe input-output waveforms.
